# Roadmap

Implemented source includes native microphone/selected computer capture, recovery journals, local/cloud speech providers, editable notes, bounded finish reports, evidence-backed retrieval, native credentials, document import, themes and reduced motion.

Still required before a production release:

- Physical Windows microphone/system-audio and long-session acceptance, device changes and overlap/echo tests.
- Actual macOS/iPhone SDK builds, permissions, capture and installation tests on Apple hardware.
- Signing, notarization and clean installation/update/uninstallation acceptance.
- Representative transcription, speaker and note/report quality evaluations.
- Hierarchical long-meeting synthesis, durable generation jobs and more incremental native storage.
- Independent privacy/security review, hosted tenant authorization, durable per-user budgets and public abuse protection.

No accounts, billing, cloud synchronization or managed-AI subscription is implemented. Do not mark these complete from CI files or source code alone.
