# Keepsake identity

The PNG masters define Buddy's folded-ribbon mark and app-icon rendition. Platform icons are generated with `npm run tauri -- icon assets/brand/keepsake-app-icon.png`; `scripts/render-installer-art.mjs` prepares installer artwork. Generated build output stays ignored. Preserve transparency and the approved silhouette.

The Buddy name and Keepsake identity are product branding; code licensing does not grant trademark rights or permission to imply an unaffiliated fork is the official service.
